# Game Menu Kit Lite for Godot 4 (free edition)

An animated main menu and options menu, ready to use. 100% typed GDScript, no image or audio
files: the background is a shader, sounds are generated by code.

- **Neon style**: synthwave background, glowing title, animated buttons and panels.
- **Main menu**: title or logo, New Game, Options, Quit with confirmation and a goodbye screen.
- **Options**: Video (display mode, resolution, VSync, frame rate, quality, render scale,
  anti-aliasing, brightness, FPS counter) and Audio (5 volumes, hover sounds, mute in background),
  applied live and saved automatically. Add your own settings.
- Soft interface sounds (3 packs), mouse / keyboard / gamepad navigation.
- English interface with a **built-in French translation**.

Compatibility: Godot **4.2 and later** (tested with 4.2 and 4.3).

*Version française : voir `README.fr.md`.*

## Installation (2 minutes)

1. Copy the `addons/game_menu_kit/` folder into your project's `addons/` folder.
2. Open **Project > Project Settings > Plugins** and enable **Game Menu Kit Lite**.
   The `MenuKit` autoload is added for you.

**Try it now**: open `addons/game_menu_kit/demo/demo.tscn` and run it with **F6**. The `demo/`
folder can be deleted safely.

## Main menu

1. Create your title scene and add `addons/game_menu_kit/main_menu.tscn` to it.
2. In the Inspector: `kicker` (small line above the title), `title_lines` (one or two lines) or
   `logo`, `footer_text`, and `new_game_scene` (the scene started by **New Game**).

`confirm_quit` asks before quitting. Signals: `new_game_requested`, `quit_requested` (when
connected, the game no longer quits by itself).

From your code:

```gdscript
MenuKit.change_scene("res://levels/level_2.tscn")
MenuKit.go_to_main_menu()
MenuKit.quit_game()  # goodbye screen, then quits
```

## Settings

```gdscript
var vsync: bool = MenuKit.settings.get_value("video/vsync")
MenuKit.setting_changed.connect(func(key: String, value: Variant) -> void:
	print(key, " = ", value))
MenuKit.settings.hide("video/render_scale")
MenuKit.settings.add_toggle("video/film_grain", "Film grain", true)
MenuKit.settings.add_range("audio/ambience", "Ambience", 80.0, 0.0, 100.0, 1.0, "%")
```

Values are saved to `user://menu_kit_settings.cfg`. Audio buses `Music`, `SFX`, `Voice` and `UI`
are created if your project doesn't have them.

To change colors or fonts: **FileSystem > right click > New Resource > MenuKitStyleNeon**, edit
it in the Inspector, then put the `.tres` path in **Project Settings > Menu Kit > Style**.

## Project settings (Project > Project Settings > Menu Kit)

| Setting | Default | Effect |
| --- | --- | --- |
| Style | `neon` | `neon` or the path of your `.tres`. |
| Sounds > Pack | `soft` | `soft`, `felt`, `minimal` (no hover sounds) or `off`. |
| Localization > Builtin French | on | French texts for French-speaking players. |
| Scenes > Main Menu | empty | Scene opened by `MenuKit.go_to_main_menu()` (found automatically). |
